Cómo funciona el acceso

Ver la información es libre. Cualquier acción que escribe datos (subir o reemplazar un documento, editar fechas, eliminar, guardar los datos del predio o del grupo, registrar una verificación de infraestructura) exige una sesión iniciada. Antes de esta autenticación cualquiera con el enlace podía escribir; hoy el servidor rechaza toda escritura sin una sesión válida.

Iniciar y cerrar sesión

Se entra con usuario y contraseña. El usuario no distingue mayúsculas; la contraseña sí. Si algo falla, el mensaje no revela si el error fue el usuario o la contraseña. La sesión dura 6 horas (el máximo que permite Apps Script) y se puede cerrar antes.

Las contraseñas nunca se guardan en texto: la hoja USUARIOS guarda sólo un resumen cifrado (hash) con una sal propia de cada usuario.

Crear usuarios

Es un equipo pequeño y de confianza, por eso no hay un rol de administrador: cualquier usuario con sesión puede crear otro (usuario, contraseña y nombre). El primer usuario se crea una sola vez desde el editor de Apps Script y esa puerta se cierra sola en cuanto existe al menos un usuario.
